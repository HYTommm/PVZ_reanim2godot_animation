R2Ga (PvZ Reanim to Godot Animation)

将植物大战僵尸的Reanim格式转换为Godot引擎动画的专业工具

当前版本: v4.1 | 基于 Tomy 库

关于R2Ga

R2Ga 是一个专门用于将植物大战僵尸(PvZ)的Flash动画特殊导出格式(.reanim)转换为Godot引擎兼容动画资源的工具。

本工具旨在帮助游戏开发者将经典的植物大战僵尸动画资源快速、高效地转换到现代游戏引擎Godot中，保留原始动画的精髓同时获得更好的性能和灵活性。

为什么选择R2Ga?

  • 专为PvZ动画转换优化，保持原始动画的精确性
  • 简化从Flash到Godot的工作流程
  • 开源免费，社区驱动开发
  • 支持批量处理，提高工作效率
  • 基于 Tomy 库 实现，提供类、容器、字符串等现代C语言增强支持

功能特点

核心功能

  • 精准转换: 专为PvZ的Reanim格式优化，确保动画转换的准确性
  • 多模式支持: 提供三种输出模式适应不同开发需求
  • 高效处理: 快速处理大量动画文件
  • 资源自动关联: 自动处理动画与素材的关联关系
  • 开源自由: 遵循GPL 3.0协议，完全免费
  • 免拼场景功能: 简化场景设置流程
  • 灵活的轨道控制: 支持可见性、纹理、透明度等轨道的独立开关
  • 每轨道更新模式: 通过配置文件为不同轨道单独指定更新模式

技术优势

R2Ga v4.0+ 采用 Tomy 库 重构，具有以下技术优势：

  • 基于Tomy库的现代化C语言实现，代码更健壮
  • 低内存占用，高性能处理
  • 精确解析Reanim二进制格式
  • 生成优化的Godot动画资源
  • 支持命令行操作与配置文件双模式，易于集成到自动化流程
  • 支持多种插值模式、帧模式、轨道模式、更新模式

关于 Tomy 库

Tomy 是一个C语言增强库，提供了类、容器（动态数组、哈希表等）、字符串等现代编程范式支持。R2Ga v4.0 起基于 Tomy 库重构，大幅提升了代码的可维护性和扩展性。

使用指南

点击观看视频教程

基本命令格式

PVZ_reanim2godot_animation.exe <输入文件> <动画路径> <资源路径> [选项]

必需参数

参数 说明
<输入文件> 输入文件路径 (.reanim格式)
<动画路径> Godot动画资源输出路径 (如: res://anim/abc/)
<资源路径> Godot资源文件路径 (如: res://art/abc/)

可选选项

选项 说明 可选值
-of, --output-file <文件> 指定输出文件路径 默认与输入文件同名
-om, --output-mode <模式> 设置输出模式 auto (默认), tscn_by_anim, anim_tres
-cf, --config-file <文件> 指定配置文件路径 —
-bm, --blend-mode 开启混合模式 (默认关闭) 开关
-nbm, --no-blend-mode 强制关闭混合模式 开关
-rnt, --root-node-type <类型> 指定根节点类型 如 Node2D, Sprite 等
-rnn, --root-node-name <名称> 指定根节点名称 —
-an, --anim-name <名称> 指定动画名称 (单动画输出时) —
-im, --interpolation-mode <模式> 设置插值模式 nearest, linear (默认), cubic
-um, --update-mode <模式> 设置更新模式 continuous, discrete, capture
-fm, --frame-mode <模式> 设置帧模式 inherit (默认), keyframe
-tm, --track-mode <模式> 设置轨道模式 separate (默认), transform
-h, --help 显示帮助信息 —

使用示例

PVZ_reanim2godot_animation.exe zombie.reanim res://animations/ res://assets/textures/ -om auto
PVZ_reanim2godot_animation.exe zombie.reanim res://anim/ res://art/ -im cubic -tm transform -bm
PVZ_reanim2godot_animation.exe zombie.reanim res://anim/ res://art/ -cf config.txt -rnt Node2D -rnn Zombie

详细步骤

  1. 准备好 .reanim 文件和对应的素材图片
  2. 确定Godot项目中存放动画和素材的路径
  3. 根据需求选择合适的转换模式及选项
  4. 运行转换命令
  5. 在Godot中导入生成的资源
  6. 测试动画效果，确保转换无误

输出模式说明

模式 描述 适用场景
auto (默认) 输出一个tscn文件和多个tres文件，并自动关联 推荐大多数情况使用，确保不会缺少任何资源
tscn_by_anim 输出一个tscn文件，包含所有动画资源 当reanim文件只包含一个动画且不需要额外资源时
anim_tres 输出多个tres文件，每个tres文件包含一个动画资源 已有场景文件，只需要动画资源时

模式选择建议

  • 推荐无脑选 auto，因为 auto 模式输出的目标文件只会多不会少。只有在特定需求下才选择其他模式。
  • 如果Reanim文件里只有一个动画，且不想有多余的动画文件产生，可选择 tscn_by_anim
  • 如果原先已经有场景文件了，且动画自己分割过，可选择 anim_tres

模式对比示例

以下是一个动画转换后不同模式输出的文件结构示例：

# auto模式输入
reanim/
└─ zombie.reanim
# auto模式输出
animations/
├─ zombie_walk.tres
├─ zombie_idle.tres
└─ zombie.tscn

# tscn_by_anim模式输入
reanim
└─ zombie.reanim
# tscn_by_anim模式输出
animations/
└─ zombie.tscn

# anim_tres模式输入
reanim/
└─ zombie_walk.reanim
# anim_tres模式输出
animations/
└─ zombie_walk.tres

插值模式说明

模式 说明
nearest 最近邻插值 — 无平滑过渡，适合像素风格
linear (默认) 线性插值 — 平滑过渡，适合大多数场景
cubic 三次方插值 — 更平滑的曲线过渡

帧模式说明

模式 说明
inherit (默认) 空字段继承上一帧的值
keyframe 空字段留空，由引擎插值

⚠️ 关键帧模式警告

关键帧模式 (keyframe) 是一种特殊模式，需要与作者魔改过的 JSFL 导出脚本配合使用，否则可能起反作用，导致动画异常。

如无特殊需求，请使用默认的 inherit 模式。

轨道模式说明

模式 说明
separate (默认) 位置/旋转/缩放/倾斜 分开为独立轨道
transform 合并为 Transform2D 轨道

⚠️ Transform 模式说明

推荐使用 transform 模式，能有效缓解原件绕圈的问题。

但请注意：transform 模式使用的是 Godot 的 隐藏 API，Godot 编辑器没有开放编辑功能，存在一定的风险。请在使用前充分测试。

更新模式说明

模式 说明
continuous 连续更新 — 每帧更新动画
discrete 离散更新 — 仅在关键帧处更新
capture 捕获模式 — 捕获当前状态

配置文件

R2Ga 支持通过 -cf, --config-file 选项指定配置文件，实现更精细的参数控制。

配置文件中的参数优先级低于命令行参数（即命令行参数会覆盖配置文件中的同名设置）。

配置文件格式

配置文件采用 键 = 值 格式，每行一个配置项。空行和以 # 开头的行会被忽略。

配置项说明

配置项 说明 可选值 备注
OutputMode 输出模式 Auto (默认), TscnByAnim, AnimTres 大小写不敏感
BlendModeEnabled 是否启用混合模式 true/1 或 false/0 默认关闭
VisibleTrackEnabled 是否启用可见性轨道 true/1 或 false/0 ⚠️ 仅配置文件
TextureTrackEnabled 是否启用纹理轨道 true/1 或 false/0 ⚠️ 仅配置文件
AlphaTrackEnabled 是否启用透明度轨道 true/1 或 false/0 ⚠️ 仅配置文件
RootNodeType 根节点类型 任意Godot节点类型 如 Node2D
RootNodeName 根节点名称 任意字符串 —
AnimName 动画名称 任意字符串 —
InterpolationMode 插值模式 Nearest, Linear (默认), Cubic 大小写不敏感
UpdateMode 全局更新模式 Continuous (默认), Discrete, Capture 大小写不敏感
FrameMode 帧模式 Inherit (默认), Keyframe 大小写不敏感
TrackMode 轨道模式 Separate (默认), Transform 大小写不敏感
UpdateModeDic.<轨道名> 为指定轨道单独设置更新模式 Continuous, Discrete, Capture ⚠️ 仅配置文件，后写覆盖

配置文件专用选项

以下选项 只能 在配置文件中设置，命令行没有对应参数：

  • VisibleTrackEnabled — 控制可见性轨道
  • TextureTrackEnabled — 控制纹理轨道
  • AlphaTrackEnabled — 控制透明度轨道
  • UpdateModeDic.<轨道名> — 每轨道独立更新模式

配置文件示例


# R2Ga 配置文件示例
# 注释行以 # 开头

OutputMode = Auto
BlendModeEnabled = true
VisibleTrackEnabled = true
TextureTrackEnabled = false
AlphaTrackEnabled = true
RootNodeType = Node2D
RootNodeName = MyZombie
InterpolationMode = Cubic
UpdateMode = Continuous
FrameMode = Inherit
TrackMode = Transform

# 为特定轨道指定更新模式
UpdateModeDic.head = Discrete
UpdateModeDic.body = Continuous
UpdateModeDic.arm = Capture

配置优先级

命令行参数 > 配置文件 > 程序默认值

如果在命令行和配置文件中同时指定了同一参数，以命令行参数为准。
