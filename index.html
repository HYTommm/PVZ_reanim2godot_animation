概览

R2Ga 将植物大战僵尸的 .reanim 动画转换为 Godot 的 .tres / .tscn 资源，并自动建立动画与贴图的关联。

主要特性

  • 为 PvZ Reanim 格式设计，保持原始动画的数值与时间精度
  • 支持 auto、tscn_by_anim、anim_tres 三种输出模式
  • 自动生成场景与动画资源之间的引用，无需手动拼装
  • 可通过配置文件控制可见性、纹理、透明度轨道，并按轨道设置更新模式
  • 支持按动画、轨道、属性排除输出
  • 命令行与配置文件双入口，便于集成到自动化流程
  • 开源，遵循 GPL 3.0

实现说明

自 v4.0 起，工程使用 Tomy 库重构。Tomy 提供类、动态数组、哈希表、 字符串等基础设施，用于替代手写容器与裸指针管理。转换器的解析与输出逻辑与原始 C 实现保持行为一致；仓库中的 cpp/ 目录是同一算法的 C++ 重写版， 通过验收脚本与 C 版逐字节比对。

本文档对应 v4.1-dev3。历史版本的参数或行为可能与此不同。

使用

基本调用

PVZ_reanim2godot_animation.exe <输入文件> <动画路径> <资源路径> [选项]

位置参数

参数 说明
<输入文件> .reanim 文件路径
<动画路径> Godot 动画资源输出路径，例如 res://anim/abc/
<资源路径> Godot 贴图资源路径，例如 res://art/abc/

三个位置参数必须按顺序书写，可以省略末尾部分，由配置文件中的 InputFile、AnimGodotPath、ResGodotPath 补齐。 三项最终必须齐全，否则程序报告参数错误。恰好三个位置参数且不带任何选项时， 仍按旧行为判定为参数错误。

最小示例

PVZ_reanim2godot_animation.exe zombie_walk.reanim res://anim/ res://art/ -om auto

操作步骤

  1. 准备 .reanim 文件及其引用的贴图。
  2. 确定动画与素材在 Godot 项目中的目标路径。
  3. 选择输出模式与需要的选项。
  4. 运行转换命令。
  5. 在 Godot 中导入生成的资源并检查动画。

视频教程： Bilibili

命令行参数

选项 说明 取值
-of, --output-file 指定输出目录 默认与输入文件相同目录
-om, --output-mode 设置输出模式 auto（默认）、tscn_by_anim、anim_tres
-cf, --config-file 指定配置文件，可重复，后加载的覆盖先加载的 配置文件路径
--print-config 打印最终生效配置及其来源后退出 开关
--init-config 输出带注释的配置模板后退出 开关
-bm, --blend-mode 开启混合模式，输出 :material 轨道 开关
-nbm, --no-blend-mode 强制关闭混合模式 开关
-rnt, --root-node-type 指定根节点类型 例如 Node2D、Sprite2D
-rnn, --root-node-name 指定根节点名称 任意字符串
-an, --anim-name 指定动画名称（单动画输出时） 任意字符串
-im, --interpolation-mode 设置插值模式 nearest、linear（默认）、cubic
-um, --update-mode 设置更新模式 continuous（默认）、discrete、capture
-fm, --frame-mode 设置帧模式 inherit（默认）、keyframe
-tm, --track-mode 设置轨道模式 separate（默认）、transform
-h, --help 显示帮助信息 —

模式说明

输出模式

模式 输出 适用场景
auto（默认） 一个 .tscn 与多个 .tres，并自动建立关联 推荐；输出文件最完整
tscn_by_anim 一个 .tscn，包含全部动画资源 输入只有一个动画，且不需要额外的动画文件
anim_tres 多个 .tres，每个文件包含一个动画 已有场景，只需要动画资源

以 zombie.reanim（包含 walk / idle 两个动画）为例：

auto
  输入:  zombie.reanim
  输出:  zombie_walk.tres
         zombie_idle.tres
         zombie.tscn

tscn_by_anim
  输入:  zombie.reanim
  输出:  zombie.tscn

anim_tres
  输入:  zombie_walk.reanim
  输出:  zombie_walk.tres

插值模式

模式 说明
nearest 最近邻插值，无平滑过渡
linear 线性插值
cubic 三次插值

rotation 与 skew 是角度属性，转换器会自动把它们的 LINEAR / CUBIC 映射为 Godot 的 LINEAR_ANGLE / CUBIC_ANGLE，避免跨 ±180° 时绕远路。

帧模式

模式 说明
inherit 空字段继承上一帧的值
keyframe 空字段留空，由引擎插值

keyframe 需要配合定制的 JSFL 导出脚本使用；使用普通导出的 .reanim 时可能导致动画异常。无特殊需求时请使用默认的 inherit。

轨道模式

模式 说明
separate 位置、旋转、缩放、倾斜分别输出为独立轨道
transform 合并为单条 Transform2D 轨道

推荐使用默认的 separate。transform 模式与 Godot 的 交叉淡入淡出不兼容：crossfade 期间会得到错误的混合姿态，只能用 Play(name, 0) 硬切。仅在明确不需要 crossfade 且需要减少轨道数时使用。

背景和复现方法见仓库中的 KNOWN-ISSUE-transform-mode.md。

更新模式

模式 说明
continuous 每一帧更新动画
discrete 仅在关键帧处更新
capture 捕获当前状态

配置文件

配置文件通过 -cf 显式指定；未指定时不会读取任何配置文件。 -cf 可以重复，按命令行顺序叠加，后加载的配置文件覆盖先加载的。

语法

  • 每行一条 键 = 值；行尾分号可选。
  • 空行和以 # 开头的行会被忽略；行内 # 之后也视为注释。
  • 值解析到行尾，可以包含空格；可以用单引号或双引号包住。
  • 键名大小写不敏感。
  • 多个键可以共享一个值：Key1 Key2 = value。
  • 字典块：UpdateModeDic = { head = Discrete, body = Continuous }。
  • 未知键会给出带行号的警告并忽略，转换继续。

排除轨道

格式：ExcludeTracks[.动画模式] = 轨道模式[:属性列表]

  • 动画模式可以写内部名（walk）、带前缀名（anim_walk） 或输出资源名（Zombie_walk）；省略动画模式表示所有动画。
  • 没有冒号表示排除整条轨道；有冒号表示只排除列出的属性。
  • 属性：visible、position、rotation、 scale、skew、transform、 texture、self_modulate（别名 alpha）、 all。多个属性用 | 分隔。
  • 动画名与轨道名大小写不敏感，均支持 * 与 ?。
  • 多个 -cf 的规则累加；命中的规则取并集。
  • 被排除的轨道不输出，也不占用 tracks/N 编号。
  • 当所有动画都不再使用某个部件时，.tscn 中不再生成对应节点。
  • transform 模式下写 position / rotation / scale / skew 会警告并忽略；separate 模式下写 transform 同理。
  • 没有命中任何轨道的规则会输出警告。
  • :material 轨道随整条轨道排除一起跳过，暂不支持单独按属性排除。
# 所有动画：整条排除 leaf
ExcludeTracks = leaf

# 所有动画：只排除 leaf 的 visible 和 texture
ExcludeTracks = leaf:visible|texture

# 仅 walk 动画：整条排除 arm；leaf 只排除 self_modulate
ExcludeTracks.walk = arm, leaf:self_modulate

# 动画名与轨道名支持通配符
ExcludeTracks.Zombie_* = eff_*

配置项

配置项 说明 取值 备注
InputFile 输入文件路径 路径 可替代第 1 个位置参数
AnimGodotPath Godot 动画资源路径 如 res://anim/ 可替代第 2 个位置参数
ResGodotPath Godot 素材资源路径 如 res://art/ 可替代第 3 个位置参数
OutputDir 输出目录 路径 等价于 -of
OutputMode 输出模式 Auto、TscnByAnim、AnimTres 大小写不敏感
BlendModeEnabled 是否启用混合模式 true/1、false/0 默认关闭
VisibleTrackEnabled 是否输出可见性轨道 true/false 仅配置文件
TextureTrackEnabled 是否输出纹理轨道 true/false 仅配置文件
AlphaTrackEnabled 是否输出透明度轨道 true/false 仅配置文件
RootNodeType 根节点类型 Godot 节点类型 默认 Node2D
RootNodeName 根节点名称 字符串 未指定时使用资源名
AnimName 动画名称 字符串 —
InterpolationMode 插值模式 Nearest、Linear、Cubic 大小写不敏感
UpdateMode 全局更新模式 Continuous、Discrete、Capture 大小写不敏感
FrameMode 帧模式 Inherit、Keyframe 大小写不敏感
TrackMode 轨道模式 Separate、Transform 大小写不敏感
UpdateModeDic 按轨道设置更新模式 字典块 同名轨道后写覆盖
ExcludeTracks 排除轨道或属性（所有动画） 见「排除轨道」 仅配置文件
ExcludeTracks.<动画模式> 只排除指定动画中的轨道或属性 见「排除轨道」 动画名支持通配符

以下配置项只能写在配置文件中，命令行没有对应选项：

  • VisibleTrackEnabled
  • TextureTrackEnabled
  • AlphaTrackEnabled
  • UpdateModeDic
  • ExcludeTracks
  • ExcludeTracks.<动画模式>

示例

# 输入输出路径；相对路径以本文件所在目录为基准
# InputFile = C:/pvz/MainGame/Zombie/Zombie_walk.reanim
AnimGodotPath = res://anim/
ResGodotPath = res://art/
OutputDir = res://anim/

# 模式
OutputMode = Auto
BlendModeEnabled = true
VisibleTrackEnabled = true
TextureTrackEnabled = false
AlphaTrackEnabled = true
RootNodeType = Node2D
RootNodeName = "My Zombie"
InterpolationMode = Cubic
UpdateMode = Continuous
FrameMode = Inherit
TrackMode = Separate

# 按轨道设置更新模式
UpdateModeDic = {
    head = Discrete,
    body = Continuous,
    arm = Capture,
}

# 排除轨道：所有动画的 leaf 只去掉 visible；walk 动画整条排除 arm
ExcludeTracks = leaf:visible
ExcludeTracks.walk = arm

下载与安装

项目遵循 GPL 3.0： GitHub 仓库 · 最新版本

安装步骤

  1. 从 Releases 下载预编译版本。
  2. 解压到任意目录。
  3. 通过命令行调用程序。
  4. 确保 Godot 项目中的动画与素材路径正确。

项目迭代较快，请使用最新版本。转换前请备份项目资源。

已知风险

  • transform 轨道模式使用 Godot 的隐藏 API，且与 crossfade 不兼容； 正式项目中使用前需充分测试。
  • keyframe 帧模式依赖定制的 JSFL 导出脚本，否则可能导致动画异常。
